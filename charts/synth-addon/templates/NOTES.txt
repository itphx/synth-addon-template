Авто-установка ресурсов в Synth (hook-Job):

Проверить результат:

  kubectl -n {{ .Release.Namespace }} logs job/{{ include "synth-addon.installJobName" . }}

  # в инстансе Synth (ADMIN-ключом):
  curl -s -H "Authorization: Bearer <ключ>" {{ .Values.autoInstall.url }}/mcp/registry
  curl -s -H "Authorization: Bearer <ключ>" {{ .Values.autoInstall.url }}/skills

Установка идемпотентна: повторный `helm upgrade` обновляет конфиг MCP и файлы
скиллов, дубликатов не появляется.
{{- else }}

Авто-установка ресурсов выключена (autoInstall.enabled=false). Включить:

  helm upgrade {{ .Release.Name }} <chart> \
    --set autoInstall.enabled=true \
    --set autoInstall.url=http://synth-backend.{{ .Release.Namespace }}.svc.cluster.local:5000/api/v2 \
    --set autoInstall.installerSecretName=synth-addon-installer

Ресурсы ставятся из `provides` в synth.pack (MCP-серверы и скиллы); подробности —
docs/deployment.md.

Внимание: add-on — внешний сервис, а не плагин. Он общается с Synth по API v2,
MCP и внешним событиям; точек расширения Extension API у него нет
(AD-086/AD-090, см. docs/contract.md).
