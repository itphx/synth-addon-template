# Support

Thanks for using the Synth add-on template! Here is where to get help.

## Documentation

- **Synth documentation portal** — <https://docs.synth.itphx.ru/> (quick start,
  providers, hybrid mode, administration, CLI/FAQ).
- **This repository** — see [README.md](./README.md), the integration contract
  [docs/contract.md](./docs/contract.md), and the configuration and deployment
  guides ([docs/configuration.md](./docs/configuration.md),
  [docs/deployment.md](./docs/deployment.md)).

## Questions and issues

- **GitHub Issues** (public mirror) —
  <https://github.com/itphx/synth-addon-template/issues>. Please use the issue
  forms and include your add-on version, Synth version and environment.
- Canonical development and issue tracking happen in GitVerse —
  <https://gitverse.ru/itphx/synth-addon-template>.

## Community and updates

- **Telegram channel** — <https://t.me/synth_dev> (announcements and releases).
- **Support section on the landing page** — <https://synth.itphx.ru/#support>.

## Security

Please do **not** report security vulnerabilities through public issues — see
[SECURITY.md](./SECURITY.md) for the private channels.
